Project: a secure environment for a web application

Goal: deploy a Node.js web application so that an attacker has to get past several independent layers. I built it in a virtual machine test lab and documented every step in a 55-page report.

What happens to a request:

  1. Firewall (UFW)Only the ports that are needed are open. Everything else is refused.
  2. Encryption (HTTPS/TLS)Nginx decrypts traffic using an X.509 certificate created with OpenSSL.
  3. Web application firewall (ModSecurity + OWASP rules)The request content is inspected for attacks such as SQL injection.
  4. Reverse proxy and load balancing (Nginx)The app is never exposed directly. Traffic is shared across three instances.
  5. Blocked: SQL injection attemptA test payload received a 403 Forbidden response on both deployed sites.
